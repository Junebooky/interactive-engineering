## Scene 19-S01 — 10-point abstract margin versus disturbance
Three hypothetical epochs natural depletion: 10−3=7≥threshold5 (toy intact); three toy disturbance tokens over exactly three epochs =>10−3−3=4<threshold5 (toy disturbed). Conceptual refresh after second epoch resets to10 then third epoch one natural loss+one token =>8≥5. This is not actual DRAM charge voltage, refresh clock, true flip count or attack threshold. m1 natural leakage versus neighboring activity distinct; m2 loss arithmetic; m3 normal REFRESH not guaranteed immunity correct. **PHYSICS/MATH PASS** for published 3-epoch examples.

**R25-01 P1: incomplete grading of valid combined student inputs `epochs=1` with `disturbanceTokens=3`, plus refresh epoch2 when only epoch1 exists.** Canonical S01 `learnerAction` exposes *independent* `epochCount=1|3` and `disturbanceTokens=0|3`, and says the three tokens are distributed **one abstract token per each of three epochs**; `modelInputs` provides outcomes only for 3 epochs and says 3 tokens distributed one each in 3-epoch case. Under student combination (epochs1,tokens3), are all 3 delivered instantly (10−1−3=6), or only one of the three planned tokens has occurred by epoch1 (10−1−1=8)? Both can be implemented from different readings but cannot both be correct. Likewise `refreshAtEpoch2=true` while epochs1 must be *not-yet-reached* or disabled, not magically trigger future reset. 
**A06 minimal deterministic correction:** distinguish `plannedTokens:0|3` from `appliedTokensAtEpoch= min(epochCount,plannedTokens)` **only if** specifying exactly one token per epoch until all planned tokens delivered; use `epochCount=1|3`, `elapsedTokenCount=(plannedTokens===3?epochCount:0)`, `rawMargin=10−epochCount−elapsedTokenCount` for no refresh, and if `refreshAtEpoch2 && epochCount===3`, reset after epoch2 and recompute final epoch3 margin8; if epochs1 and refreshAtEpoch2 selected, state `REFRESH_NOT_REACHED`, no reset. Example epochs1 tokens0=>9, epochs1 planned3=>8, epochs3 planned3=>4, epochs3 planned3+refresh2=>8. Alternatively explicitly choose `disturbanceTokensTotal` that all occur during chosen observation window without 1per epoch requirement, then initial1/3 outputs differ and the canonical narrative needs rewrite. **Do not call tokens real ACT count or production DRAM refresh threshold.**
**Negative:** epoch1/planned3 must never be arbitrarily assigned both outcomes6 and8 as correct; refresh epoch2 when only one epoch elapsed must not instantly reset to10; correct-first and intentional negative feedback test.

## Scene 19-S04 — toy extended Hamming SECDED
8-bit (4 data,3 parity,1 global parity) extended Hamming code toy: syndrome and overall parity together can correct **one** flipped bit, detect **two** without correcting, and **three or more aren't guaranteed** detected or corrected; some patterns may miscorrect. `eccLayer=onDie|system|both|none` only a schematic *location/scope*, not a guarantee that real on-die ECC code is Hamming(8,4) or protects full channel. If `eccLayer=none`, do not claim detection of two bit errors; source says no decoder correction and should explicitly state unobservable syndrome. **P2** add `decoderActive=(eccLayer!=='none')` derived, and without active ECC `detectionResult=NOT_OBSERVED` not "TWO_DETECTED_NOT_CORRECTED" on layer none. For layer both, toy one-decoder math is conceptual not independent guarantee of 2-stage actual hardware. PHYSICS/MATH PASS under enabled decoder assumptions.
