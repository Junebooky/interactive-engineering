## Lesson 29 deep independent review, 5 steps
### Numerics/physics independently PASS
1. **S01 SerDes**: PCIe lane independent TX/RX pathways full duplex; x4 theoretical line capacity 4× x1 if comparable training/per-dir overhead; PAM4 four amplitude symbols=2 bits/symbol; NRZ two=1. Does NOT double PCIe GT/s.
2. **S02 PCI-SIG official FAQ** PCIe7 128GT/s with x16 headline **512 GB/s bidirectional aggregate**; one-direction envelope 256, x4 one-direction64. PCIe6 64GT/s x16 both256/one128, x4 one32. Not payload. PCI-SIG official https://pcisig.com/what-data-rate-pcie-70-specification directly confirmed line declaring figures. GT/s is official spec rate; multiplying by PAM4 bits/symbol again would double count.
3. **S03 PCI-SIG Aug19 2021 original FAQ** PCIe6 fixed 256B FLIT, TLP-carrying 236B, `236/256=0.921875=92.1875%`; *space for TLPs*, not net user payload. TLP may span multiple FLITs, FLIT may carry multiple TLPs, other20 B for overhead; cannot assert PCIe7 236/256 layout. Source: https://pcisig.com/blog/pcie%C2%AE-60-specification-webinar-qa-deeper-dive-flit-mode-pam4-and-forward-error-correction-fec
4. **S04 kernel DMA** DMA_FROM_DEVICE means **device→main memory** (so NVMe READ payload SSD→host DDR), DMA_TO_DEVICE reverse, *not* direction of user's command. CPU virtual VA vs physical vs device-visible DMA address can differ due to IOMMU/host bridge; IOMMU presence optional. Linux guide https://docs.kernel.org/6.15/core-api/dma-api-howto.html . Linux PCI P2P https://docs.kernel.org/driver-api/pci/p2pdma.html explains same PCI hierarchy/ACS routes may work, cross root port not universal; **provider and client driver cooperation and MMIO/DMABUF or compatible P2P memory support mandatory**.
5. **S05 CXL Consortium open web sources** CXL.io config/registers, CXL.cache device accesses coherent host memory, CXL.mem host accesses attached memory in supported device types; not equal to NVMe queue or local DRAM latency. Toy 100×3=300, 10×1 +90×3=280 **cost units**. 128GT/s CXL4 announcement is link headline; no app GB/s or ns latency guarantee; CXL4 restricted evaluation-license document **NOT USED**. Public sources https://computeexpresslink.org/blog/the-benefits-of-serial-attached-memory-with-compute-express-link-2349/ and https://computeexpresslink.org/blog/questions-from-the-compute-express-link-exploring-coherent-memory-and-innovative-use-cases-webinar-2341/ .
